# 05: Pera o Kahon

**What to build:** The single surviving Finalist is offered a real choice between Pera and the Kahon. Pera is the small guaranteed voucher; the Kahon draws at random from a table of larger prizes, and may return Bokya. The Stage names the winning prize exactly as it is written on the item physically handed over.

This is the payoff the whole show has been building toward, so it lands last: a Finalist has to exist before the choice means anything.

**Blocked by:** 04 — The bracket.

**Status:** ready-for-agent

- [ ] The Finalist is offered an unhurried, clear choice between Pera and the Kahon, and the choice is genuinely theirs
- [ ] Taking Pera resolves to the fixed small guaranteed voucher
- [ ] Opening the Kahon draws from the prize table through the injected generator rather than from a random source the machine owns
- [ ] A pinned generator reproduces the same draw on every run, so a rehearsal is repeatable
- [ ] Bokya is reachable as a genuine outcome from the table and carries its own sound, distinct from a win
- [ ] The Stage names the winning prize exactly as it appears in the content, so the screen can never contradict the item being handed over

- [ ] The prop box moment is operator-triggered rather than automatic, so the presenter holding it controls when it opens
